# Online (CICS) runtime + signon/menus

Session 6 port: the shared online framework (`framework/`) plus COSGN00C, COMEN01C, COADM01C.

## Layout
- `framework/runtime.ts` `OnlineRuntime` - terminals, TRANSID dispatch (CSD table), EIB (`EIBCALEN`, `EIBAID`, ...), XCTL/LINK/RETURN TRANSID COMMAREA chaining, syncpoint at task end, rollback + `DFHAC2206` screen on abend.
- `framework/cics.ts` `CicsContext` - the `EXEC CICS` surface a program uses: `sendMap`, `receiveMap`, `sendText`, `return`, `xctl`, `link`, `inquireProgram`, `assign`, `asktime`, `writeqTd`, `syncpoint`, `syncpointRollback`, `abend`, `abendHandler` (HANDLE ABEND), `files` (READ [UPDATE]/WRITE/REWRITE/DELETE/UNLOCK/STARTBR/READNEXT/READPREV/RESETBR/ENDBR with RESP/RESP2, over the Session 1 `CicsFileControl`), `track()` to copy a file RESP into the EIB.
- `framework/bms/` - `maps.generated.ts` (all 17 maps, generated by `npm run gen:bms` from `app/bms/*.bms` and cross-checked against `app/cpy-bms/*.CPY`), `SymbolicMap` (xxxL/F/A/C/H/I/O slots), screen model (SEND MAP ERASE/DATAONLY/MAPONLY/CURSOR, RECEIVE MAP with JUSTIFY and MAPFAIL, SEND TEXT, 24x80 rendering).
- `framework/aid.ts` (DFHAID, `storePfKey` = CSSTRPFY), `bmsca.ts` (DFHBMSCA attributes/colours), `resp.ts` (DFHRESP incl. PGMIDERR/MAPFAIL), `commarea.ts` (`CarddemoCommarea` byte view of COCOM01Y), `helpers.ts` (CSDAT01Y dates, COTTL01Y titles, CSMSG01Y/02Y, `populateHeaderInfo`, NUMVAL/NUMVAL-C/TEST-NUMVAL[-C], `cobolString`, `formatEdited`/`deEdit`, `csutldtc`, CSLKPCDY lookups).
- `signon/`, `menu/` - the three program ports; `areas/*.ts` + `programs.ts` - registration.
- `server/` - `npm run online` HTTP JSON API + browser 3270 terminal (`GET /`).

## HTTP API
- `POST /api/transaction/{transid}` `{ terminalId?, aid?, fields? }` - start a transaction (new terminal if none given).
- `POST /api/terminal/{id}` `{ aid: "ENTER"|"PF3"|..., fields: { USERID: "...", ... } }` - input to the pending RETURN TRANSID.
- `GET /api/terminal/{id}`, `GET /api/transactions`.
Responses: `{ terminalId, transid, programs, program, nextTransid, commarea, abend, screen: { map, mapset, cursor, fields[], lines[24] } }`.

## LIMITATIONS
- CICS programs cannot run under GnuCOBOL, so expected values in the tests were derived by tracing the COBOL source (no golden files).
- **COMEN01C deviation**: for a menu option whose program is not registered (not ported yet) the port uses the COPAUS0C path ("This option <name> is not installed...", red) instead of XCTL raising an unhandled PGMIDERR (abend AEI0). COPAUS0C itself follows the COBOL INQUIRE PROGRAM logic. COADM01C needs no deviation: its HANDLE CONDITION PGMIDERR message ("... is not installed ...", green) is reproduced, including the quirk that the commarea is already set to CDEMO-PGM-ENTER, so the next input re-displays a fresh menu.
- Out-of-range option subscripts (0, 12-99, non-numeric) read storage outside the COMEN02Y table in COBOL; the port treats that entry's user type as not 'A'.
- Fresh WORKING-STORAGE (symbolic maps, CARDDEMO-COMMAREA in COSGN00C) is modelled as LOW-VALUES.
- RECEIVE MAP never raises (CardDemo always codes RESP); file commands always return RESP. Unhandled XCTL/LINK PGMIDERR becomes an abend (AEI0). Program checks (JS exceptions) abend ASRA.
- All CSD files are RECOVERY(NONE), so by default SYNCPOINT ROLLBACK and abends do not back out file updates (as in CICS). Pass `recoverableFiles` to `OnlineRuntime` to journal and back out specific files.
- Screen model: one map per screen (SEND MAP without ERASE replaces the previous map), no partial-field overtyping (typed input replaces the whole field; unfilled positions are nulls), numeric-lock allows digits, `.`, `-` and space. Abend/unknown-transaction texts mimic DFHAC2206/DFHAC2001 but are not byte-exact. A transaction whose program is not registered abends APCT. APPLID/SYSID default to `CARDDEMO`/`CDEM`.
