## 2. Stored rows re-encode to the source bytes

Every row is read back through JPA, turned into its copybook record (`toRecord()` + `CopybookRecordMapper`, IBM-037) and compared with the source record of the same key. ## 6. Idempotency

Table contents are fingerprinted as `count(*)` + md5 of all rows (`string_agg(t::text)` in a fixed order) after the first load, after a forced second `REPLACE` run (`run.id=2`) and after an `UPSERT` run (`carddemo.initial-load.mode=upsert`). Relaunching with the first run's parameters is refused (`JobInstanceAlreadyCompleteException`), which is how the `local`-profile startup runner skips data it has already loaded.
