# Decisions reserved for the system owner (CBTRN04C)

None of the items below is decided by this change. The programs and JCL are
delivered so that either answer can be implemented without rework of the
validation logic; where a default behaviour had to exist to make the code run it
is stated under "Evidence" and can be changed by the owner's decision.
