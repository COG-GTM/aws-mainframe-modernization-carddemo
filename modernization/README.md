# Modernization — CardDemo slivers

COBOL batch programs taken off the mainframe into idiomatic Java, one sliver at a time, working
only from the static export in this repository (`app/cbl`, `app/cpy`, `app/jcl`, `app/asm`,
`app/data`). No mainframe connectivity was used or available.

| Module | What it is |
| --- | --- |
| [`carddemo-mainframe-io/`](carddemo-mainframe-io) | Shared, sliver-independent record I/O: EBCDIC text, zoned and packed decimal codecs, COBOL fixed-point semantics, `RecordLayout` declarations for the CardDemo copybooks, DB2 timestamp formatting |
| [`interest-service/`](interest-service) | Sliver 1 — `CBACT04C`, monthly interest accrual (`app/jcl/INTCALC.jcl`) |
| [`transaction-posting-service/`](transaction-posting-service) | Sliver 2 — `CBTRN02C`, daily transaction posting (`app/jcl/POSTTRAN.jcl`) |

| Deliverable | Sliver 1 | Sliver 2 |
| --- | --- | --- |
| Business logic map (for a business SME) | [`CBACT04C-logic-map.md`](CBACT04C-logic-map.md) | [`CBTRN02C-logic-map.md`](CBTRN02C-logic-map.md) |
| Black-box parity harness | [`interest-service/.../parity`](interest-service/src/test/java/com/carddemo/interest/parity) | [`transaction-posting-service/.../parity`](transaction-posting-service/src/test/java/com/carddemo/posting/parity) |
| Parity report (generated by the harness) | [`PARITY-REPORT.md`](PARITY-REPORT.md) | [`PARITY-REPORT-CBTRN02C.md`](PARITY-REPORT-CBTRN02C.md) |

The procedure both slivers followed, with the effort delta between them, is
[`SLIVER-PLAYBOOK.md`](SLIVER-PLAYBOOK.md).

## Running it

```bash
cd modernization
mvn test          # both slivers; regenerates PARITY-REPORT.md and PARITY-REPORT-CBTRN02C.md
```

To run the jobs themselves — the Java equivalents of the two JCL steps:

```bash
# //STEP15 EXEC PGM=CBACT04C,PARM='2022071800'
mvn -q -pl interest-service -am compile
java -cp interest-service/target/classes:carddemo-mainframe-io/target/classes \
  com.carddemo.interest.batch.InterestCalculationJob ../app/data/EBCDIC target/output 2022071800

# //STEP15 EXEC PGM=CBTRN02C
mvn -q -pl transaction-posting-service -am compile
java -cp transaction-posting-service/target/classes:carddemo-mainframe-io/target/classes \
  com.carddemo.posting.batch.DailyTransactionPostingJob ../app/data/EBCDIC
```

The posting job prints the two `DISPLAY` counters and exits with the COBOL return code (4 when
anything was rejected), per `app/cbl/CBTRN02C.cbl:226-232`.
