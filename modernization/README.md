# Modernization — CBACT04C interest calculation sliver

One COBOL batch program taken off the mainframe into idiomatic Java, working only from the static
export in this repository (`app/cbl`, `app/cpy`, `app/jcl`, `app/asm`, `app/data`). No mainframe
connectivity was used or available.

| Deliverable | Path |
| --- | --- |
| Business logic map (for a business SME) | [`CBACT04C-logic-map.md`](CBACT04C-logic-map.md) |
| Java 21 Maven module | [`interest-service/`](interest-service) |
| Black-box parity harness | [`interest-service/src/test/java/com/carddemo/interest/parity`](interest-service/src/test/java/com/carddemo/interest/parity) |
| Parity report (generated by the harness) | [`PARITY-REPORT.md`](PARITY-REPORT.md) |
| Reusable procedure for the next sliver | [`SLIVER-PLAYBOOK.md`](SLIVER-PLAYBOOK.md) |

## Running it

```bash
cd modernization/interest-service
mvn test          # runs the parity harness and regenerates ../PARITY-REPORT.md
```

To run the job itself, the Java equivalent of `//STEP15 EXEC PGM=CBACT04C,PARM='2022071800'`:

```bash
mvn -q compile
java -cp target/classes \
  com.carddemo.interest.batch.InterestCalculationJob ../../app/data/EBCDIC target/output 2022071800
```

It writes an updated `ACCTFILE` image and a `TRANSACT` (`RECFM=F,LRECL=350`) image into
`target/output`, both in EBCDIC, per the DD mapping in `app/jcl/INTCALC.jcl`.
